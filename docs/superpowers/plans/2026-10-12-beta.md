# Beta Implementation Plan

> For agentic workers: use executing-plans for root integration, dispatching-parallel-agents for non-overlapping profile/engine/QA tasks. User explicitly requested continuous autonomous execution, overriding extra design approval stops.

**Goal:** 一次导入、一次维护、可信重复填写的可安装本地Beta候选。
**Architecture:** 静态本机站、MV3加密主档案、明确批准的loopback桥；共享模型与引擎，独立测试及Windows自带运行时。
**Tech Stack:** 原生JS、WebCrypto、既有PDF.js/fflate、Chrome/Edge MV3、Node24、Windows C#启动器。
**Spec:** docs/superpowers/specs/2026-10-12-beta.md

## Global Constraints
- 保留既有37独立模拟通过与44基线；原目录不覆盖、不写真实企业申请、不自动提交、不公开推送。
- 独立checkout为当前job-beta；Beta端口47841、版本0.4.0，显示Beta RC1。
- 所有扩展共用模块由build-extension同步；字体对应源码/许可证随包，私人快照不进Git。

## Review Focus
1. 连接未批准、错误origin/tab/nonce、超量请求必须失败；后台不接收口令/明文。
2. 网页与扩展并发保存CAS；连接断开后不默默保存到另一份档案。
3. 自定义搜索框、重复选项、旧节点或框架回滚不能显示成功。
4. 敏感问题、家庭资料与同意/提交始终保留人工；日期和最高学历不猜测。
5. 附件、来源和版本可加密恢复，旧档案迁移不损坏；源码与发行目录分离。
