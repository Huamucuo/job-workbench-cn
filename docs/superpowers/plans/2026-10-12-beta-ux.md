# Beta普通使用流程简化（用户最新调整）

用户要求：简单易懂，不做重复操作。此前原37项及安全事实不改变；新UX语义与对应证据单独保留，不将旧测量当成新运行结果。

1. 首页导入/档案入口在扩展已安装且没有未迁移离线档案时直接打开锁定扩展档案。只打开固定UI不返回数据，所以无需每页反复批准。storage全部仍需精确origin/tab/nonce明确grant；过期/刷新规则不放宽。
2. 网页共用与旧档案迁移成为按需高级功能：已有不同离线数据时提示本人选择，不擅自绕过迁移/覆盖决策；可以继续离线资料。
3. 普通导入主动作是本人核对后“确认导入并加密保存”，减少重复保存；保留“仅加入草稿”用于不完整资料。未核对前不写有效档案，CAS失败不覆盖，后续手动编辑仍本人保存。
4. 填写仍识别→核对预览→确认填写，下一步和最终提交均手动。安装一次；不同浏览器仍通过加密备份迁移，不用两边重新录入。
5. 新增实际Edge未批准仅openUI可用/敏感存储仍拒绝/旧资料不忽略测试、一次导入确认保存/草稿保留/CAS保护测试；更新普通指南并做受影响回归。原37、原失败证据、旧冻结包保留。

不新增账号、付费API、广泛host权限、静默安装或公开部署；不重做页面/项目。高级验收报告与详细技术说明不挤进普通主流程。
