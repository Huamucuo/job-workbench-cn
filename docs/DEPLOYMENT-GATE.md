# 源码公开与公共网站部署门禁

维护者批准公开源码，仅允许公开经审查的代码、虚构样本与有许可依据的第三方资源。它不自动批准真实岗位数据分发、招聘服务运营或公共网站部署。

config/release.json 的五项批准字段必须依据实际证据逐项审查：源码/数据公开范围、运营者与地区适用、通信及招聘要求、隐私与日志、实际网络访问。投诉联络方式和各来源的 redistributionAllowed / permissionEvidence 也需真实建立。

当前这些批准字段保持 false，投诉联络方式为空，五个来源未取得再分发依据。npm run build:public 应继续拒绝。不得只为通过构建把字段设为 true。CI 的本机构建和空数据校验不替代来源许可或运营审查。

本候选未加入定时更新、Cloudflare 部署或生产 Secrets。今后上线需独立提交方案、数据范围、许可依据、真实访问测试及人工批准；免费使用与免费额度并不免除适用要求。
