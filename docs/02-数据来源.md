# 数据来源与公开边界

公开源码保留原接口适配与来源 registry，不附带真实岗位快照、公告正文或缓存。初次初始化为零条岗位，不用虚构数据冒充当前可报名岗位。

| 原研究来源 | 官方入口 / 接口说明 | 本项目状态 |
| --- | --- | --- |
| Cloudflare 招聘 / Greenhouse | https://www.cloudflare.com/careers/jobs/ · https://docs.greenhouse.io/job-board.html | 自动公开采集与再分发许可未确认 |
| Ashby 招聘 / Ashby API | https://www.ashbyhq.com/careers · https://developers.ashbyhq.com/docs/public-job-posting-api | 自动公开采集与再分发许可未确认 |
| Greenhouse 招聘 | https://www.greenhouse.com/careers · https://docs.greenhouse.io/job-board.html | 自动公开采集与再分发许可未确认 |
| 国资委招聘公告 | https://www.sasac.gov.cn/n2588035/n2588325/index.html | 人工公告和原文核验待独立审核 |
| 华为校园招聘 | https://career.huawei.com/cn/campus-recruitment | 报名状态、转载和采集范围待独立审核 |

registry 中 automatedAllowed / redistributionAllowed 保持 false，permissionEvidence 为空。接口能访问不等于已获得聚合转载授权。npm run update 没有获准来源时应拒绝；update:research 是使用者主动发起的本机研究入口，不能当作公开定时运营或数据发布许可。

接入新来源时记录权利/条款依据、允许的内容与频率、原文入口、核验与失败处理。人工公告不因软件执行成功就变成“正在报名”。源码公开与招聘数据服务上线分别批准，参见 [公共部署门禁](DEPLOYMENT-GATE.md)。
