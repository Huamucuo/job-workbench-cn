# 架构

本机静态网页 + 仅监听 127.0.0.1 的 Node.js 服务。岗位数据与个人记录分离，收藏和投递状态不写入岗位 JSON。

public/autofill 提供档案、加密 vault、规则、填表引擎和导入预览；build-extension只复制白名单模块和依赖，网页与扩展引擎逐字节一致。Beta扩展持有加密主档案；工作台经过明确批准可以共用，未选择共用时仍有明确标示的离线档案。两边已有不同资料时必须选择来源，不默认覆盖。不同浏览器仍需加密备份迁移。

新用户的首页资料入口只打开扩展固定options界面，不读取资料、不隐式批准连接。正常导入在预览核对后一次保存；仅草稿模式折叠保留。旧数据选择与网页共用编辑才需要连接批准。网页link不自动打开缺少activeTab的弹窗，用户通过真实工具栏手势授权。

## 数据流与授权

普通用户的入口是Windows发行目录“开始使用.exe”，自带Node24.19。本机HTTP服务只监听127.0.0.1:47841，仅GET/HEAD，拒绝不匹配Host、Origin及cross-site请求。`/__health`提供版本/PID；`/__installation`提供准确扩展目录，不提供简历读取或写入接口。

扩展content script在隔离环境中运行。manifest匹配http://127.0.0.1/*，脚本与background再严格检查47841、允许的顶层路径、标签页ID和32字节随机文档nonce。页面postMessage→content script→background；弹窗由本人勾选并批准最长30分钟。刷新后的新nonce不继承授权；可撤销全部连接。请求尺寸、方法、键和加密封包格式有界；不接收口令或明文简历。storage.local/session只向可信扩展上下文开放。

CanonicalStore队列统一处理有效档案CAS和恢复草稿原子追加/消费。有效档案保存以expectedCiphertext验证旧版本，并一次写入主档案/上一版/对应草稿清理；陈旧窗口拒绝覆盖。草稿操作在同一队列内读、追加、校验、写，防止不同origin的WebLocks造成丢失。共享模式断线后拒绝保存，不转存另一份数据库。

档案AES-GCM-256、PBKDF2-SHA256/600000，随机salt/IV，口令不入存储。解锁页内存保留明文，闲置5分钟或本人锁定清除；未完成修改只保存加密恢复草稿，不成为可填写档案。浏览器数据被删除/扩展卸载可能丢失，请先导出加密备份。最多2份512KiB附件，加密前档案总内容3MB，扩展恢复草稿最多5份。

## 识别与执行边界

扩展只有activeTab/scripting/storage权限。本人点击目标页工具栏后注入共用引擎；读页面结构、字段标签与已填状态，预览后再写入。姓名/联系人上下文、家庭/证件/声明保护、日期精度、最高学历来源都在推断、记忆和人工映射路径重新验证。先后两次扫描ID或节点结构改变就跳过。自定义adapter仅识别有界、归属明确、唯一的选项；触发器与选项拒绝不安全交互祖先/标签默认激活。

原生原型setter与input/change/click同步受控字段，再在有界等待内回读和检查回滚。正式网站后端是否保存无法仅靠DOM证明，用户仍需核对；本机complex-checker同时读取独立模型和模拟保存层，不假装验证全部React/Vue。引擎不请求提交、点击下一步或声明；任意网站脚本对输入的后续动作不在通用保证范围内，真实站点按具体页面验收。

DOCX 用 fflate 提取 XML；PDF 用本地 PDF.js 与 worker 提取文字，不使用 CDN/外部 AI，不执行简历宏或外链。导入先形成草稿与来源，确认后保存有效档案。

公开源码不附真实岗位；初始化创建空的被忽略文件。sources/registry.json 保留接口与许可状态，config/release.json 公共部署门禁保持关闭。

WindowsZIP也不附真实岗位。原机可把既有研究快照单独放在新发行目录.local/jobs.json，HTTP只对/data/jobs.json返回该快照；不改日期，不纳入ZIP/Git。收藏、薪资条件、标签与投递记录保留原localStorage契约，通过原有私有备份恢复。
