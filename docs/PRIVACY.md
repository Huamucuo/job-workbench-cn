# 私有资料与公开范围

个人档案、简历、原文、字段来源、加密备份、收藏和投递记录均不上传仓库或 CI 附件。加密文件也不自动适合公开。

本候选只含源码、虚构输入和经审查的第三方材料。真实岗位、人工公告、本机日志、用户截图、冻结包和缓存排除。samples 的简历使用示例域名并明确虚构，不能投递。

导入默认本机处理；填表需逐项确认，目标网站可即时读取输入。初始化独占创建缺失文件，不覆盖数据，不访问招聘接口。

本机审查报告留在仓库外的 review 目录，绝不作为公开文件自动上传。

Beta的受批准连接仅传加密封包和字段对应结构，不通过HTTP服务传送档案口令/明文。与网页共用前需要本人批准当前页并明确选择来源；撤销或过期后读取/保存失败，不退回另一份档案。即使知道本机端口，其他网页、其他端口及iframe也不能读取扩展档案。

字段对应记忆在本机记录站点/路径、字段结构签名和档案字段路径，不保存填写值。它不是加密简历内容；可在填写面板清除，涉及特殊站点标签时也应作为私有数据处理。收藏、投递、备注沿用本机存储，未作为加密档案保护；导出时会提示为个人备份。

PDF/DOCX原文件不自动长期保留。提取的原文、文件SHA、字段来源、歧义和用户确认记录随档案加密。附件只有本人明确添加后才随档案保存；不自动上传招聘网站，不上传AI。当前候选没有AI开关、账号、统计分析或第三方简历服务。

解锁后的网页/扩展内存和本人确认填写的招聘页能接触明文。恶意浏览器插件、本机恶意程序、被篡改的本机源码或目标站点不能靠本产品消除；不把“加密本机保存”当作网站端安全保证。密码不上传，不支持忘记口令找回。
