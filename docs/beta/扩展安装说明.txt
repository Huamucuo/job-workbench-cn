职有引力 · 扩展 0.4.2 Beta

推荐普通 Windows 用户下载完整 Windows 包，里面已有扩展、安装助手和图文教学，无需重复下载。

如果你只下载了这个扩展单独包：
1. 把整个 ZIP 全部解压。
2. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions。
3. 清空搜索，打开开发人员模式，点击“加载解压缩的扩展”。
4. 选择解压后的 extension 整个文件夹，不要选择 manifest.json 或 ZIP。
5. 看到“职有引力 · 本机求职填表”0.4.2，保持启用并固定工具栏。
6. 从扩展的“我的档案”导入自己的 DOCX / 文字版 PDF，核对后确认保存（默认免口令）。
7. 招聘页点工具栏扩展 → 开始跨页填写 → 开始本次网申 → 每页核对并填写；仅开启口令保护时需解锁一次。

这个单独包没有 Windows EXE。图文教学里的安装助手属于完整 Windows 包。
系统要求本人确认安装；不静默安装、不改浏览器策略。已验证隔离 Edge/Chrome 的实际扩展运行，不代表你日常浏览器已安装。
