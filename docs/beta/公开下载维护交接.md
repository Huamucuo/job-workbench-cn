# 职有引力 0.4.2 Beta 1 维护交接

本版继续现有项目，基线 a1da1a2，独立分支 release/public-download-0.4.2；原0.4.1/0.4.0冻结目录、Git标签和测试真值保留。软件源码公开发行与公共招聘服务部署分开，config/release.json的部署合规门禁仍为false。

普通用户下载一个Windows ZIP即可。包内开始使用.exe、安装扩展.exe和图文教学.html/PDF是三个主要入口，自带Node24.19。不用账号、命令、API密钥或付费服务；浏览器要求本人完成开发人员模式和加载目录，尚未商店上架。

## 关键维护位置

- public/autofill/profile-ui.mjs：导入/修改/确认保存/备份恢复及可选保护界面，构建时复制到extension/autofill。档案版本schemaVersion2延续原数据结构。
- public/autofill/vault.mjs：旧口令封包继续可读；unlockMode=device为本机免口令档案。自动访问资料仅存浏览器本机，不能当口令保护，不能传给网页桥或包含在公开包里。
- extension/background.mjs + bridge-policy.mjs：可信扩展页面专用本机访问接口、存储白名单、授权与原子CAS队列。网页连接只能传受支持的密文；不开放明文或本机访问资料。
- extension/sidepanel.mjs：单次网申授权、页面自动扫描与失效取消。默认为免口令开始；旧保护模式输入一次口令。标签页、来源、申请标识、5分钟闲置和30分钟最长授权仍有效。
- windows/ExtensionInstaller.cs：原生安装助手，只读取本包目录、复制路径与用户点击后打开浏览器管理页。/describe及/renderguide供维护者验证，不冒充普通用户已安装。
- scripts/package-download.mjs + download-policy.mjs：明确白名单、空岗位、私有目录拒绝、ZIP全量回读和SHA256。运行前指定已核验运行时及对应LICENSE，最终目录存在即拒绝覆盖。
- public/help/onboarding.html/css/：离线图解；PDF由同一HTML生成，全部页面渲染后目视验收。图像只含明确虚构档案与隔离浏览器。

## 本机数据和恢复

每个浏览器保留自己的扩展档案。清理、换目录、换浏览器前先导出档案备份。免口令备份是未加密的完整JSON，导出会提示；保护模式导出原兼容加密格式。两种备份都先在我的档案中预览，确认保存才替换有效档案。并发保存检测旧密文版本，不覆盖另一窗口的新资料。

开启口令保护仅保护当前有效档案；上一版与旧免口令恢复草稿仍保留，本机访问资料也仍可用于它们。UI在开启前说明此边界，不声称删除了历史副本。需要完整隔离时，先导出保护备份，再在新浏览器档案恢复。保留旧草稿是避免资料丢失的选择。

## 版本回退

先备份当前资料，并停止本版自己拥有的服务。原0.4.1冻结程序与标签 v0.4.1-rc.1-local-delivery保持可用。回退扩展时应在独立浏览器档案中加载旧版，不能让两个副本同时使用。0.4.1不能读取新的免口令封包/未加密备份：先在0.4.2开启口令保护并导出兼容加密备份，或继续保留0.4.2以恢复资料。不要删除当前扩展、真实档案、旧程序或备份。

源码可以从保留的Git标签创建独立分支。不要重写已公开历史；新的修复通过PR和新的Beta版本，不覆盖旧Release资产。GitHub source ZIP不包含运行环境，不能代替普通用户Windows ZIP。

## 复测与公开边界

规则/服务器、原37项、默认免口令、旧口令保护、跨页、真实侧栏和全新ZIP启动的结果见本版验收报告；原始HAR、trace、浏览器profile、个人档案与私有岗位fixture仅在.local，永不上传。

维护者可运行docs/TESTING.md列出的命令。浏览器测试用短的独立profile路径，不使用日常资料；Windows路径过长可触发LevelDB LOCK错误。使用47961的跨页、47841的档案/连接和47842/47943的原模拟表单不得抢占同一端口。只停止有PID+路径+启动时间证据的本任务服务。

公开包岗位初始为空，岗位搜索/薪资/收藏/标签/投递记录代码完整保留。本版没有扩大数据转载授权。扫描OCR、旧DOC、加密PDF、跨源iframe、任意ShadowDOM和未知控件不保证支持；附件/验证码/声明/最终提交保留人工。用户免除真人耗时对照，不得宣称实证节时30%。商店发布、真人日常浏览器手动安装和真实站点全面兼容另行验证。
