# 职有引力 · 求职工作台

中文优先、免费使用的求职工作台。采用 Build in Public，通过功能分支、Pull Request、独立审查和版本记录持续开发。

**当前版本：v0.3.0 开发候选。源码公开与正式稳定版发布分开进行。** 本候选不附带真实岗位快照、个人简历或用户截图；尚未验证全部真实招聘网站，也没有上线公共招聘服务。

## 当前功能

- 有来源和核验状态的岗位搜索、多条件筛选、薪资口径与官方入口。
- 当前浏览器中的收藏、投递阶段、标签、备注、保存条件及私有备份。
- 本机加密求职档案；导入 DOCX 和可提取文字的 PDF，预览、修订、处理冲突并确认保存。
- Chrome / Edge MV3 填表扩展原型：识别字段、逐项核对、确认填写和已有内容保护。
- 明确标注虚构的简历与 A/B/C 表单，分别验收网页演练助手和已安装的扩展。

不自动投递、处理验证码、勾选声明或推进真实网页的下一步。填写后的网站可以立即读取输入，使用者必须本人核对。

## 安装与启动

安装 [Node.js](https://nodejs.org/) 24 或以上版本。浏览器依赖随源码提供，无需 npm install。在新下载的项目目录运行：

~~~text
npm run prepare:local
npm test
npm run build:extension
npm run package:extension
npm start
~~~

打开 http://127.0.0.1:47831 。Windows 完成初始化后，也可双击“开始使用.cmd”。初始化只创建缺失的本机文件，不覆盖已有数据。

公开源码没有附带真实招聘数据，初次岗位列表为空是预期行为。可先使用档案管理、简历导入和模拟表单。真实来源接入须另行审核许可、核验与采集频率，不把虚构表单当成真实岗位。

扩展需要手动安装：打开 edge://extensions 或 chrome://extensions，开启开发者模式，选择本项目的整个 extension 文件夹。package:extension 在本机生成可选 ZIP；解压后仍选择其中的 extension。本项目不会自动安装到日常浏览器。

先用虚构样本演练“导入 → 预览 → 修改 → 确认加密保存 → 模拟表单 → 扩展识别 → 核对 → 填写”，不要向真实企业投递测试简历。

## 验证与限制

本轮自动化结果见 [测试说明](docs/TESTING.md)。历史 v0.3.0 共用引擎网页演练的已定义目标合计 46/46；C 包含人工映射，该结果不能证明扩展上下文或真实网站全部兼容。没有真人手填基线，不承诺节时比例。

仍需独立验证日常浏览器安装、MV3 的 PDF/DOCX 导入、实际扩展填表和真实网站控件。GitHub Actions 已准备，实际远程执行结果须在批准上传后核实。

2026-10-12 对北森 iTalent 的只读结构检查发现邻近标签、自定义选择器、单选与日期控件等尚未适配；v0.3.0 不能可靠填写该网站。该检查没有输入个人资料或提交申请，也不算兼容性通过。

不支持扫描件 OCR、旧 DOC、加密 PDF；复杂结构需人工归类。iframe、Shadow DOM、自定义组合控件、文件上传、证件、声明及验证码保留人工处理。网页和扩展通过加密备份迁移档案，没有隐式同步。浏览器或访问地址改变会形成不同的本机记录空间。

公开可访问的招聘接口不自动授予转载或持续采集权限；公开部署门禁保持关闭。
