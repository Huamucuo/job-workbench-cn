# 职有引力 · 求职工作台

中文优先、免费使用的求职工作台。采用 Build in Public，通过功能分支、Pull Request、独立审查和版本记录持续开发。

**当前版本：0.4.1 Beta 跨页候选（扩展版本号 0.4.1）。** 从现有 v0.3.0 源码继续开发，历史 v0.2.1 的模拟验收继续保留。Beta 的重点是导入一次简历、确认一份档案，再在招聘表单中复用。GitHub 提供本机候选的源码、虚构测试样本、操作说明与验收摘要；Windows 安装包目前通过本机交付，尚未上线公共招聘服务。

GitHub Actions 仅运行离线测试与源码构建，不部署网站、采集岗位或发布安装包。个人档案、真实岗位快照、浏览器资料、原始运行日志和宣传视频不进入源码仓库。

## 当前功能

- 有来源和核验状态的岗位搜索、多条件筛选、薪资口径与官方入口。
- 当前浏览器中的收藏、投递阶段、标签、备注、保存条件及私有备份。
- 本机加密求职档案；导入 DOCX 和可提取文字的 PDF，预览、修订、处理冲突并确认保存。
- Chrome / Edge MV3 填表扩展：常驻侧栏保持本次解锁，跨页、刷新、回退和同地址换步自动准备预览；逐页核对后填写，分类反馈和失败重试。原单页入口保留。
- 扩展持有加密主档案；工作台经过逐页授权后可共用。连接不会传送口令或明文简历，旧资料迁移需要明确选择来源。
- 学历与学位分开；多段教育、实习、工作、项目、技能、证书、语言与自我介绍均可编辑。描述版本只改变用户写入的职责与介绍文本。
- 本机附件加密保存与核验下载；加密备份、上一版恢复、独立恢复草稿、并发保存保护。
- 明确标注虚构的简历与 A/B/C/F 表单；分别检查页面值、受控模型值、保存值和模拟提交计数。

不自动投递、处理验证码、勾选声明或推进真实网页的下一步。填写后的网站可以立即读取输入，使用者必须本人核对。

## 安装与启动

普通 Windows 用户使用本机交付的 `求职工作台-Beta-0.4.1-rc.1-Windows.zip`：全部解压，双击 **开始使用.exe**，打开首页四个入口。运行时随包提供，不需要输入命令、安装 Node 或注册账号。详细图文说明见 [跨页填写与首次使用](docs/beta/跨页填写说明.html)。

在 Edge 中打开 `edge://extensions`，清空搜索，开启开发人员模式，点击“加载解压缩的扩展”，选择 Windows 发行文件夹中的 **extension**。Chrome 使用 `chrome://extensions`。不会静默安装；开发或测试浏览器里已加载不等于日常浏览器已安装。扩展的准确路径会显示在工作台“安装扩展”页。

安装后回首页刷新，点击“导入简历”直接打开扩展档案；设置不少于12字符口令，导入DOCX或文本PDF，核对来源、歧义与冲突，点击一次“确认导入并加密保存”。日常在目标表单点击工具栏扩展 → 开始跨页填写 → 解锁一次。后续每页自动准备预览；核对后点击“核对并填写本页”。无需重复批准网页连接；旧档案迁移或网页编辑共用档案时，才在首页折叠入口明确连接与选择来源。网站的下一步和最终提交均由本人操作。

维护者从源码运行：

安装 [Node.js](https://nodejs.org/) 24 或以上版本。浏览器依赖随源码提供，无需 npm install。在新下载的项目目录运行：

~~~text
npm run prepare:local
npm test
npm run build:extension
npm run package:extension
npm start
~~~

打开 http://127.0.0.1:47841 。Windows 源码完成初始化后，也可双击“开始使用.cmd”。初始化只创建缺失的本机文件，不覆盖已有数据。旧版继续使用原目录与 47831 端口，不会被 Beta 覆盖。

源码与 ZIP 没有附带未经许可的第三方岗位快照，初次岗位列表为空是预期行为。原电脑上既有的本机研究快照可以在独立发行目录 `.local/jobs.json` 保留；它不进 Git/ZIP，不改写发布时间、核验时间或状态。真实来源接入须另行审核许可、核验与采集频率，不把虚构表单当成真实岗位。

共享连接限定 `http://127.0.0.1:47841` 的指定顶层页面；每次刷新或新开工作台页面必须重新批准，授权有效 30 分钟并可撤销。选中共享档案后，断线不会悄悄改存另一份离线档案。明文只在解锁后的页面内存和本人确认填写的目标网页中使用。

先用虚构样本演练“导入 → 预览 → 修改 → 确认加密保存 → 模拟表单 → 扩展识别 → 核对 → 填写”，不要向真实企业投递测试简历。

跨页操作与六页完整网申练习见 [跨页填写说明](docs/beta/跨页填写说明.html)。原0.4.0冻结发行目录保留；扩展需本人安装或更新，隔离测试不代表日常浏览器已更新。

## 验证与限制

0.4.1实测结果见 [跨页验收报告](docs/beta/跨页验收报告.html) 与 [维护测试说明](docs/TESTING.md)。[0.4.0 Beta验收报告](docs/beta/验收报告.html)保留历史结果，不能作为新增跨页能力的证据。历史 v0.3.0 共用引擎演练 46/46、v0.2.1 独立 37 项仍作为独立历史记录，不拿旧结果冒充新候选的运行证据。真人完整耗时对照已由用户明确免除；自动化耗时对照会报告实际方法、结果及限制，不承诺真人节时比例。

2026-10-12 对北森 iTalent 的只读结构检查没有输入或提交申请。Beta 对其相似的 Phoenix 选择器、邻近标签和 DIV 单选进行本机虚构复现，不能据此宣布真实站点全面兼容。Greenhouse、Ashby、北森及其他真实系统需要在具体页面由本人核对；最终实测范围和失败项见报告。

不支持扫描件 OCR、旧 DOC、加密 PDF；复杂排版、未标明的字段、需要推断的身份信息均保留待确认。iframe、Shadow DOM、任意自定义控件、文件上传、证件、声明及验证码保留人工处理。多级选择只接受受支持的控件结构和唯一明确的选项，不猜最高学历。描述版本不生成经历。附件最多 2 份、每份 512KiB，总原始数据 1MiB；加密前档案总内容上限 3MB。忘记口令不能替你找回；请导出备份并妥善保存口令。

公开可访问的招聘接口不自动授予转载或持续采集权限；公开部署门禁保持关闭。
