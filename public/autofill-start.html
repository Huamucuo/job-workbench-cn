① 安装扩展② 导入简历③ 开始填写虚构资料练习

1. 双击启动，再手动安装扩展

ZIP全部解压到可写目录后，双击开始使用.exe。程序自带运行环境，不用输入开发命令。Windows 10/11 64位本机候选，未签名的自制启动器可能被系统提示；请核对来自你的交付目录。

  1. Edge地址栏输入 edge://extensions（Chrome用 chrome://extensions）。清空搜索，打开开发人员模式。
  2. 点击“加载解压缩的扩展”，选择下方完整文件夹。不要选择源码文件或未解压ZIP。
  3. 名称“职有引力 · 本机求职填表”，扩展版本0.4.0；开启开关，固定到浏览器工具栏。已有旧版先保留加密备份，避免同时启用两个副本。
  4. 返回工作台首页刷新，安装状态会在连接卡片上显示。

本机版本：0.4.0 Beta RC1。浏览器要求用户手动安装，不会静默安装；设备管理策略限制时联系管理员。

2. 导入一次，核对后一次保存

  1. 安装完成回首页刷新，点击“导入简历”直接打开扩展档案。不需先批准网页连接。
  2. 首次设置不少于12字符口令，点击“导入已有简历”，选择DOCX或有文字层的PDF，可多选。
  3. 核对原文来源、多段经历、日期、学历/学位和身份信息；修订候选，明确选择冲突。
  4. 勾选已核对，点击确认导入并加密保存。看到保存成功即可，扩展直接复用，不需再点第二次保存。
  5. 日后修改在“我的档案”确认加密保存。未完成草稿不会用于填写，闲置5分钟锁定；请保留口令并导出加密备份。
旧资料迁移与网页编辑（按需）

首页检测到旧离线档案时，展开“旧资料迁移与网页连接”，先连接并由本人在工具栏批准，再点“共用这份档案”，下载备份后明确选择来源，不默认覆盖。迁移后无需日常重复连接。只有网页读写共用档案才需逐页批准，最长30分钟；刷新后重新批准。只打开扩展档案界面不授予资料读取权限。

口令、明文简历不通过本机HTTP传送；连接失败不会偷偷转存另一份档案。附件最多2份、每份512KiB，本机加密保存；多个表述版本只修改本人写入的描述。

3. 识别 → 预览 → 填写 → 检查

  1. 正常打开招聘表单，完成网站自己的登录。点扩展，输入本机口令解锁。
  2. 选择已保存的资料表述版本。识别当前页；需要多条经历时先准备经历分组，等待异步加载。
  3. 核对目标网站、姓名、联系方式、经历顺序、日期与选项。最高学历等汇总项需明确指定来源教育记录。含义不明确就保留人工；可保存本人确认过的对应关系。
  4. 已有内容默认保护，覆盖需要逐项确认。勾选核对确认，点“填写已勾选字段”。等待结果，查看已完成、失败、跳过、待确认。
  5. 检查网站字段。控制组件未保存或把值回滚时不能视作成功；修正后重新识别或重试。下一步由本人点击，新步骤重新识别。

助手不会最终提交、处理验证码或替你确认声明。证件、健康、宗教、家庭、紧急联系人和工会等问题保留本人处理。网站可能在输入时即时读取资料，请先确认目标站点。

4. 先用虚构资料验收

下载虚构PDF/DOCX；导入、编辑、保存并锁定重开。然后打开A/B/C和复杂测试页，勾选“使用已安装的扩展验收”，从浏览器工具栏操作，点击独立检查并保存报告。错误关键资料必须0、提交必须0；需要人工处理的项会说明原因。

5. 原记录与回退

原0.2.1/0.3.0目录和冻结版本保留。升级前在旧版导出“本机记录备份”和“加密档案”，在Beta对应入口导入；此后共用主档案。新备份含新字段时不要交给不支持它的旧版。

退出双击“停止工作台.exe”。回退先停止Beta，再启动原目录“开始使用.cmd”。版本源码分支和基线Tag随本地源码包交接；未推送公开发布。

招聘搜索、薪资、收藏、标签和投递功能保留。ZIP不包含未经许可的岗位快照；原机可继续使用本机研究快照，核验时间不重写，过期条目不能冒充在招。

已知边界

本地文字PDF/DOCX优先，不支持扫描OCR、旧DOC、密码PDF。复杂多栏或文本框可能需要人工核对。自定义控件只支持已识别的有限结构；iframe、Shadow DOM、虚拟列表、非标准富文本和未验收站点可能保留手工填写。北森iTalent已检查真实结构，本地同类控件已新增适配，真实企业填表尚未全部验收。
