先分清：网页 ≠ 已安装的扩展

工作台和 Codex 内置浏览器不会自动替你的日常 Edge 安装扩展。这一页也不能读取 Edge 的扩展列表，是否安装、是否启用，以你当前 Edge 的扩展管理页为准。测试通过不表示已经安装。

你在扩展管理页搜索不到“职有引力”时，请按下面步骤加载本机文件夹。本扩展尚未上架商店。

STEP 01

安装到你日常使用的 Edge

  1. 在 Edge 地址栏输入 edge://extensions。
  2. 清空左侧搜索框，打开左下角“开发人员模式”。
  3. 点击“加载解压缩的扩展”，选择下方整个安装文件夹，不要选择某个代码文件。
  4. 找到“职有引力 · 本机求职填表”，确认版本为 0.3.0、开关已开启。点击浏览器右上角拼图图标，把它显示/固定在工具栏。
  5. 已安装过：在扩展管理页点击该扩展的“重新加载”，再刷新招聘表单网页。不要同时装多个副本。
下载扩展安装包 ZIP

请选择你下载的项目目录内的 extension 文件夹。ZIP需先解压，再选择里面的 extension 文件夹。换目录可能形成另一个扩展存储空间，先导出加密档案备份。

权限与故障排查

仅申请当前页面临时权限、执行填表脚本和本机存储（activeTab、scripting、storage）。请在目标表单标签页点击扩展图标来授予本次临时访问；不需要开启所有网站的永久读取。

若看不到图标，打开拼图菜单固定它。若页面不可访问，确认是 HTTPS 招聘网页或本机测试页，浏览器内部页面和商店不可填写。企业策略禁止开发者扩展时，由管理员处理。Chrome对应管理页为 chrome://extensions。

STEP 02

选择资料 → 识别 → 预览 → 填写 → 核对

  1. 选择资料：点工具栏扩展 →“档案管理”。新建或解锁你的统一档案，点击“导入 PDF / DOCX 简历”，核对、修改并确认加密保存。已有工作台档案可导出加密文件，在扩展内导入并保存；两边用同一种档案格式，修改后需重新导入。
  2. 返回目标表单：切回招聘网站的填写页面。练习时先用下方虚构表单。扩展只处理你当前打开的页面。
  3. 识别字段：点工具栏扩展，输入本机档案口令，解锁后点“识别当前页”。需要多条经历时先点“准备经历分组”。
  4. 检查预览：逐项核对目标网址、姓名、电话、学校、经历序号和日期。未匹配的字段可以手工选择对应关系；不确定就取消勾选。
  5. 自动填写：勾选“我已核对目标网站及所选资料”，点“填写已勾选字段”。已有内容默认不覆盖；需要替换的项目必须单独确认。
  6. 回到网页核对：等“本次结果”出现，检查实际网页中的值。下一步、验证码、声明与最终提交均由你本人处理。网页可能在输入时立即接收资料。
