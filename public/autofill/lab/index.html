➜ 安装扩展与开始自动填写指引

可检查的原型 · v0.2.1

少填一次，也要填对。

这里有三种真实可操作的测试表单。内置助手与 Chrome / Edge 扩展使用同一套识别和填写引擎，仅使用明确标注的虚构资料。没有真实申请会被提交。

先核对网站和字段，再填写。不会猜测缺失的日期，不会处理验证码或替你勾选同意条款。扩展手工安装后，可在每页勾选“使用已安装的扩展验收”。

A · 中文标准表单

普通文本、邮箱、电话、下拉、年月；保留已有城市，跳过验证码和敏感字段。

打开测试 A →

B · 英文与动态经历

英文名称、ARIA 标签、自动准备第二段教育经历。检查两所学校没有填串。

打开测试 B →

C · 多步骤与保守跳过

单选、多选、人工更正字段并记忆、下一步后重新识别；年月不自动补日。

打开测试 C →

D · 防错边界回归

额外检查紧急联系人、折叠经历、禁用组、多选顺序和预览后手工修改。

打开边界回归 →

E · 独立验收问题的开发回归

家庭成员、表格实习、延迟新增、地区级联及异常停止；开发检查不能代替独立扩展复测。

打开开发回归 →

怎么判断可用

  1. 先识别、核对预览，勾选确认后填写。
  2. 点击“检查填写结果”，查看正确项、未填项、错填项及提交计数。
  3. 错误关键资料必须为 0；未填项应有明确原因。
  4. 用同一虚构档案手工填写计时，再对比辅助填写时间。没有人工基线时不显示节时百分比。
  5. 保存报告。可运行原型不代表已兼容真实招聘网站。

统一档案可在扩展内新建并载入虚构测试档案，或从工作台导入加密备份。真实个人资料请勿放入测试网页或项目文件夹。
